An entry for the make.fun bounty **"The poem about permission"**: a 129-character poem about asking for — and finding — permission within oneself.

```
Knock, and the door remembers it was wood —
grain opening like a palm.
I asked the dark for a candle.
The dark said: you are one.
```

## How to run

```sh
node main.ts
```

`main.ts` (Node 22, stdlib only, no network) writes the poem to `entry.txt` inside the directory given by the `MAKEFUN_OUTPUT_DIR` environment variable (default `/output`), creating the directory if needed.
